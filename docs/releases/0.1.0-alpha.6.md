# Tracebox 0.1.0-alpha.6

## Release scope

Alpha.6 adds a narrowly bounded public performance-observation primitive needed by Tracker's local
battery, wakeup, startup, and memory diagnostics. It also carries forward the completed alpha.5
Tracker consumer qualification and makes the completed personal-release checklist a required host
readiness condition.

## Highlights

- Adds `TraceboxLogger.performanceEvent(LogTemplate, LogArgument...)` for low-volume instantaneous
  host observations that are not elapsed-duration measurements.
- Uses the existing independently controlled performance category, static bounded template,
  explicit privacy classification, message-size, and argument-count contracts.
- Does not apply the minimum-duration threshold to an instantaneous event; the event remains a
  no-op unless performance logging is enabled.
- Adds no sampler, polling loop, aggregation, time-series database, identifier, network client, or
  upload behavior. Hosts own when an observation is made.
- Preserves the unchanged deterministic schema/package format and the hash-locked four-ABI native
  payload. Tracker ships only `arm64-v8a` in its production artifacts.

## Published modules

The release publishes `tracebox`, `tracebox-api`, `tracebox-core`, `tracebox-storage`,
`tracebox-directboot`, `tracebox-anr-exit`, `tracebox-export`, `tracebox-export-ui`,
`tracebox-native`, and `tracebox-ui-compose`. The reusable native AAR continues to contain
`arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`; host applications choose their shipped ABI set.

## Qualification

The exact release source must pass all 14 bounded host-readiness gates and the Linux release-content
job. The focused runtime tests prove that instantaneous observations are independently gated,
privacy-rendered, recorded with zero duration and no outcome, and unaffected by the duration
threshold. Tracker additionally consumes an isolated ten-module candidate and verifies its
ARM64-only packaging plus startup, lifecycle resource, and source-timer measurement contracts.

The native inputs and `.tbdiag` schema/package format are unchanged, so the existing representative
API 36 native/emulator evidence remains the accepted qualification for those surfaces.

## Tracker consumption

Use `0.1.0-alpha.6` for Tracker's normal GitHub Packages dependencies after publication. Pin the
immutable AAR checksums and release source/tag identity; do not use Maven Local or a candidate
override in production or CI.
