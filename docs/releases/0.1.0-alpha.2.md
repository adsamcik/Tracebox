# Tracebox 0.1.0-alpha.2

Tracebox 0.1.0-alpha.2 is the first alpha intended for direct use in Tracker. It provides one runtime-controlled diagnostics system for application logs, performance measurements, handled exceptions, fatal JVM failures, ANRs, historical process exits, and optional native crash capture.

## Artifacts

Applications can select only the capabilities they use:

- `io.github.tracebox:tracebox` — managed Android runtime, storage, capture, and export API.
- `io.github.tracebox:tracebox-native` — optional Crashpad/native capture integration.
- `io.github.tracebox:tracebox-ui-compose` — optional Compose diagnostics settings, review, save, share, and deletion UI.

The base `tracebox` artifact does not bring `tracebox-native` as a transitive dependency.
Android consumers enable core-library desugaring with
`com.android.tools:desugar_jdk_libs_nio:2.1.5` for API 23+ NIO support.

## Application API

- Template-and-parameter logging through `Tracebox.log` with `verbose`, `debug`, `info`, `warn`, and `error` levels.
- Privacy-aware parameters through `public`, `sensitive`, `pii`, `secret`, and immutable application privacy adapters.
- Synchronous and suspending performance measurements through `Tracebox.log.performance` and `performanceSuspend`.
- Handled exception capture through `Tracebox.crashes.record` and automatic fatal JVM capture after installation.
- Persisted runtime policy for master enablement, log levels, Logcat mirroring, performance thresholds, and managed/native/ANR/process-exit capture.
- A reusable `TraceboxDiagnosticsScreen` and `TraceboxDiagnosticsActivity` for applications that do not want to build diagnostics UI.

Privacy transformation occurs before text reaches Logcat or durable Tracebox storage. Logging checks policy before formatting parameters so disabled calls remain cheap.

## Capture and storage

- Detailed log, exception, and ANR records are stored with bounded schema fields.
- Android `ApplicationExitInfo` records are imported through their raw trace adapter when available.
- Installation has a process-wide handle and safe no-op access before initialization.
- Native installation and native policy handoff are activated only when the application opts into the native artifact and enables native capture.

## Validation completed for this alpha

- Android JVM unit tests for all Tracebox modules.
- Release AAR assembly for managed, native, and Compose UI artifacts.
- A managed-only APK build and emulator launch with no native libraries packaged.
- Schema compiler tests and checked-in generated-artifact drift verification.
- Rust workspace tests.
- Tracker compilation, focused unit suites, debug APK assembly, and one x86_64 emulator smoke run covering managed installation, native handler startup, and durable Tracebox files.

This is a personal-project alpha. Broader device qualification, long-duration ANR tuning, battery benchmarking, and multi-device release certification are intentionally evaluation work rather than blockers for using the alpha in Tracker.
