# Tracebox 0.1.0-alpha.5

## Release scope

Alpha.5 is the immutable publication roll-forward for the fully qualified alpha.4
implementation. It makes no runtime, public API, schema, package-format, or privacy-contract
change. The alpha.4 tag is preserved for audit after its workflow failed before creating any
GitHub release, draft, or Maven package.

## Highlights

- Aligns Tracebox with Tracker's Gradle 9.6.1, AGP 9.3.1, Kotlin 2.4.10,
  coroutines 1.11.0, JDK 21/Java 17, and Android SDK 37 toolchain.
- Enforces static logging templates, classified bounded arguments, structurally message-free JVM
  crash capture, equivalent privacy-adapter configuration, and deterministic schema/package
  compatibility.
- Bounds the runtime to one explicitly disposable approved package and wipes owned package or
  staging bytes on replacement, policy change, deletion, runtime close, and screen disposal.
- Ships the resource-backed diagnostics UI and its policy, review, recreation, delivery, RTL,
  large-font, accessibility, and cleanup coverage.
- Keeps Tracebox local-first with no endpoint, HTTP client, Internet permission, retry worker,
  analytics identifier, or automatic upload.
- Requires both complete Windows host readiness and the exact Linux release build before tagging;
  native/emulator qualification remains in bounded manual or scheduled lanes.
- Versions the already-qualified Crashpad libraries for all four ABIs as reviewed release inputs,
  with byte, SHA-256, source-provenance, and first-party input-tree locks. Clean CI and tag builds
  therefore package the same native bytes instead of relying on ignored workstation outputs.

## Published modules

The release publishes `tracebox`, `tracebox-api`, `tracebox-core`, `tracebox-storage`,
`tracebox-directboot`, `tracebox-anr-exit`, `tracebox-export`, `tracebox-export-ui`,
`tracebox-native`, and `tracebox-ui-compose`. Native packaging covers `arm64-v8a`,
`armeabi-v7a`, `x86`, and `x86_64`.

## Qualification

All host/static gates and malicious corpora pass. All 13 required personal-release scenarios pass
on the ADR-0010 API 36 `x86_64`, 4 KiB emulator. Because alpha.5 changes only release engineering,
the product qualification evidence remains
`evidence/personal-release/API36-x86_64-4096-alpha4.json`.

## Tracker consumption

Use `0.1.0-alpha.5` for Tracker's normal GitHub Packages dependencies. Pin the immutable AARs and
verification hashes after publication; no Maven Local fallback is required.
