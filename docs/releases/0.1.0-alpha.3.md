# Tracebox 0.1.0-alpha.3

## Highlights

- Reworks the optional Compose diagnostics screen into a casual-user-first
  reviewed send/share flow with advanced controls collapsed by default.
- Adds `TraceboxDiagnosticsUiConfiguration` for app-owned actions, policy reset
  defaults, editable logging/performance/capture controls, copy, and layout.
- Adds the host-owned `TraceboxDiagnosticUploader` contract for sending exact
  approved package bytes through an application's existing backend stack.
- Keeps Tracebox transport-free: no endpoint, HTTP client, Internet permission,
  retry worker, or new native dependency is added.
- Keeps the exact disclosure and approval boundary mandatory before upload.
- Replaces the approval activity's raw technical-first dump with a plain package
  summary, explicit approve/cancel actions, and opt-in exact technical details.

## Tracker integration

Tracker uses a prominent “review and share with developer” action, retains save
and deletion, and keeps every technical control under the collapsed advanced
section. Direct upload remains disabled until Tracker supplies a real backend.
