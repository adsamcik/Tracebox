# Tracebox 0.1.0-alpha.4

## Highlights

- Aligns Tracebox with Tracker's Gradle 9.6.1, AGP 9.3.1, Kotlin 2.4.10,
  coroutines 1.11.0, JDK 21/Java 17, and Android SDK 37 toolchain.
- Makes full host readiness a required CI gate for all ten published AARs while
  retaining bounded manual or scheduled native/emulator qualification.
- Enforces static logging templates and explicitly privacy-classified runtime
  arguments through the API and the consumer-facing fatal lint rule.
- Removes the JVM capture message field and opt-in policy, so throwable messages
  cannot enter a managed crash record.
- Treats equivalent privacy adapters as equivalent installation configuration,
  without relying on the same configuration-container instance.
- Bounds the runtime to one approved package, exposes only scoped exact-byte
  reads, and wipes package/staging ownership on replacement, policy change,
  deletion, runtime close, and diagnostics-screen disposal.
- Freezes deterministic package record/schema compatibility with canonical
  ZIP/CBOR validation, Kotlin/Rust goldens, and append-only schema checks.
- Moves diagnostics UI copy into overridable resources and covers policy,
  review, approval, recreation, upload-disabled behavior, save/share, deletion,
  RTL, large fonts, accessibility semantics, and staging cleanup.
- Keeps Crashpad metadata outside the full raw-capture reserve so a maximum-size
  native handoff can be consumed on the first restart without degrading the
  replacement handler.

## Published modules

The release publishes `tracebox`, `tracebox-api`, `tracebox-core`,
`tracebox-storage`, `tracebox-directboot`, `tracebox-anr-exit`,
`tracebox-export`, `tracebox-export-ui`, `tracebox-native`, and
`tracebox-ui-compose`. Native packaging covers `arm64-v8a`, `armeabi-v7a`,
`x86`, and `x86_64`.

## Privacy and transport boundary

Tracebox remains local-first and owns no endpoint, HTTP client, Internet
permission, retry worker, analytics identifier, or automatic upload. Static
templates and classified arguments exclude exception messages and host data
such as coordinates, network identifiers, URIs, filenames, user text, and
database contents. A host-owned uploader can read only the exact bounded bytes
the user reviewed and approved.

## Qualification

The required host/static gates and malicious corpora pass. All 13 required
personal-release scenarios pass on the single ADR-0010 endpoint: API 36,
`x86_64`, 4 KiB pages. The evidence covers readiness, handler replacement, JVM
and native fatal capture/restart ingestion, live ANR capture, OS-exit
reconciliation, deletion/restart, disclosure/approval, save/share cleanup, and
UID-scoped no-network controls.

Evidence: `evidence/personal-release/API36-x86_64-4096-alpha4.json`.

## Tracker consumption

Use version `0.1.0-alpha.4` for the normal Tracker dependencies. Tracker should
pin the immutable GitHub Packages artifacts and verification hashes after this
release is published; no Maven Local fallback is required.
