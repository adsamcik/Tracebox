# Code of Conduct

Tracebox contributors are expected to be respectful, constructive, and
professional. Harassment, discrimination, threats, personal attacks, and
deliberate privacy or security harm are not acceptable.

## Reporting

Use the repository's private maintainer contact or GitHub private reporting
mechanism when it is configured. Do not publish sensitive details in a public
issue. Before the first public release, repository administrators must configure
a real private reporting channel and replace this paragraph with its address or
GitHub link.

Maintainers will review reports privately, protect reporter confidentiality as
far as practical, and may remove content or restrict participation when this
code is violated.
