# Security policy

## Supported versions

Only the current alpha line is maintained while the project is pre-certification:

| Version | Supported |
| --- | --- |
| 0.1.0-alpha.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or privacy flaw.
Use GitHub's private vulnerability reporting for the repository once it is
enabled, or contact a repository maintainer through a private channel.

Before publishing the first public GitHub release, an administrator must enable
private vulnerability reporting and add its concrete repository URL here. This
source tree intentionally does not invent an email address or response-time
commitment.

Tracebox treats accidental collection, retention, export, or network activity as
security-relevant even when no traditional exploit is involved.
